# ChoseWay 红黑赛博科技风 —— 完整设计规范

> 提炼自 ChoseWay Manager（`web/src/styles.css`）、报价单工具、ChoseWayAssetsViewer 的共同视觉语言。本文是规范正文，[theme.css](theme.css) 是可引入实现，[SKILL.md](SKILL.md) 是速查。
> 气质关键词：**深空近黑 · 玻璃拟态 · 红色点睛 · 大圆角胶囊 · 细网格纹理 · 克制的赛博光效 · 游戏片头感**。它是「运营后台 + 科技感」而非「霓虹赛博朋克」——红只有一抹，没有紫青霓虹、没有大面积发光。

---

## 1. 视觉基调

- 只有暗色。整站 `color-scheme: dark`，背景几乎纯黑，所有「面」都是黑底上叠加 2%~7% 的白色半透明，而不是用灰色实色。
- 层次靠**透明度阶梯**而非色相：面板 4% 白、悬停 7% 白、描边 9% 白、强描边 16% 白。
- 红色是唯一的品牌色，用法有三种且仅三种：① 主操作（主按钮 / Logo / 头像兜底 / 滑杆把手）；② 角落氛围（左上角径向红晕、卡片左上 135° 斜向淡红渐变）；③ 语义警示（逾期 / 危险 / 急且重 / 今天线 / 离线）。
- 文字偏暖（`#f4efe9` 带一点米色），与纯黑底形成柔和对比；不要用冷白。
- 科技感来自：细网格底纹、斜切形状、DIN 风格斜体描边大数字、等宽终端字、辉光状态点、克制的脉动动效，以及开场「故障闪现」动画。

### 2.2 派生色（写死在各处的常用值）

- 红色文字（在红底 / 红胶囊上）：`#ffb3ba`；红胶囊底 `rgba(212,18,31,.16~.18)`、描边 `rgba(255,82,95,.22~.45)`。
- 金色系（重要 / 临期）：主 `#e8b54a`（渐变到 `#c9902e`）、文字 `#ffd98a`、底 `rgba(232,181,74,.13)`、描边 `rgba(232,181,74,.42)`；警告标签用 `--warn #d9a13b`。
- 橙色系（仅紧急）：`#ff8c3b → #d9720e`（甘特里用 `#e07a2f`）。
- 普通 / 灰：色条 `rgba(255,255,255,.22)`，甘特 `#4a443f`；整卡 `opacity: .68`。
- 蓝（仅「关联 / 链接到别处」小标签）：`#7fa0dc`，描边 `rgba(127,160,220,.35)`。
- 性别图标：♂ 冷蓝 `#7fb4ff` / ♀ 暖粉 `#ff9ccc`。
- 类别标签按名称哈希取色（8 色）：`['#ff6b6b','#d9a13b','#46c576','#4fa3d9','#9a7bd9','#d96bb1','#4fc2bd','#c9b458']`，用法：文字 = 该色、描边 = 该色 40%、底 = 该色 12%。哈希 = 字符码求和取模。
- 开场动画辅助色：扫描线暖红 `rgba(255,130,120,.85)`、青色细线 `rgba(0,229,255,.4)`、闪白 `#ff6a5e`、终端字 `#8f867d`。

### 2.3 用色比例

黑灰 ≥ 90%，暖白文字，红色 ≤ 5%（主按钮、几个状态点、一条色条、角落光晕），金 / 橙 / 绿 / 蓝只在状态语义处出现。如果一屏里红色超过一两处大面积，就错了。

## 3. 页面背景配方（必做）

```css
body {
  background:
    radial-gradient(circle at 0% 0%, rgba(212,18,31,.22), transparent 24%),   /* 左上红晕 */
    radial-gradient(circle at 100% 0%, rgba(255,255,255,.06), transparent 16%), /* 右上微白晕 */
    linear-gradient(180deg, #0b0b0b 0%, #111 45%, #060606 100%);              /* 竖向深灰 */
  background-attachment: fixed;
}
body::before {   /* 34px 细网格，向下渐隐 */
  content: ""; position: fixed; inset: 0; pointer-events: none;
  background:
    linear-gradient(90deg, rgba(255,255,255,.025) 1px, transparent 1px),
    linear-gradient(rgba(255,255,255,.018) 1px, transparent 1px);
  background-size: 34px 34px;
  mask-image: linear-gradient(180deg, rgba(0,0,0,.88), transparent 92%);
}
```

- 小窗口（桌面小组件 320×600）同样配方但红晕范围放大到 34%，容器加 22px 圆角与 11% 白描边。
- 全屏覆盖层（速览）用 `rgba(7,7,7,.62)` 遮罩即可，不再叠网格。
- 选区 `::selection { background: var(--red-dim) }`；滚动条 10px、拇指 14% 白圆角 5px 带 2px `#0b0b0b` 边、轨道透明。

## 4. 字体与排版

- 字体栈：`"Segoe UI", "PingFang SC", "Microsoft YaHei", "微软雅黑", system-ui, sans-serif`；`-webkit-font-smoothing: antialiased`。
- 基准：根 14px，行高 1.6。
- 字号梯度：页面标题 26px / 700 / `-0.03em`；弹窗标题 18px / 700 / `-0.02em`；卡片标题 13.5~14.5px / 700；正文 13px；次要 12~12.5px；辅助 11~11.5px；角标 10~10.5px；眉标 12px。
- **眉标（面板 / 看板列 / 表头 / 仪表盘卡片头）**：12px / 700 / 大写 / `letter-spacing: .08em`（表头 .06em）/ 颜色 `rgba(255,255,255,.62)`（表头用 `--faint`）。
- Logo 副标：10.5px / 600 / 大写 / `.14em` / `--faint`。
- **大号数字**：`'Bahnschrift','DIN Alternate','Arial Narrow','Segoe UI'`，700，**斜体**，`letter-spacing: -.04em`，`font-variant-numeric: tabular-nums`；装饰性进度数字用 `color: transparent; -webkit-text-stroke: 1.5px rgba(255,55,72,.45)` 描边效果（46px），编辑态用实色 `#ffb3ba`（34px）。
- 等宽：`Consolas, monospace`（密码框、日志时间、终端引导文字、文件名用 `ui-monospace`）。
- 中文界面为主，按钮 / 标签 / 导航文字一律 700 字重。

## 5. 形状、边框、玻璃与阴影

- 圆角梯度：28px（侧栏、登录卡、弹窗）→ 24（入口卡）→ 22（面板、看板列、仪表盘卡）→ 20（资产卡）→ 18（行卡、团队本人块）→ 14（任务卡、输入框、导航项、下拉 / 右键菜单、图标块）→ 12~13（成员块、分类树、小图标块）→ 9~10（菜单项、内部小行）→ 7~8（icon-btn、键帽、色块）。胶囊 `999px` 用于按钮、标签、筛选 chip、分段控件、toast、计数徽标。
- 描边永远 1px 白色半透明（9% 默认、16% 强），**不用彩色实线描边**，除非是语义（红 / 金 / 绿 / 类别色）胶囊。
- 玻璃面板配方：`background: linear-gradient(180deg, rgba(255,255,255,.04), rgba(255,255,255,.018)); border: 1px solid var(--line); backdrop-filter: blur(12px);`
- 实底浮层配方（菜单 / 弹窗 / toast / 右键）：上述渐变叠在 `rgba(14~16,14~16,14~16,.96~.97)` 上，描边 10~12% 白，`blur(10~14px)`，投影 `0 24px 60px rgba(0,0,0,.55)`。
- 悬停在实底卡上：`transform: translateY(-3px); border-color: var(--line-strong); box-shadow: 0 18px 40px rgba(0,0,0,.28)`。
- 红色投影只跟红色元素：主按钮 `0 14px 28px rgba(212,18,31,.28)`（悬停 .38 + `brightness(1.08)`），Logo 方块 `0 10px 22px rgba(212,18,31,.28)`。
- 输入类控件底色用 `rgba(0,0,0,.2)`（比面板更沉一层），圆角 14px，描边 10% 白。
- 角落斜向氛围渐变：登录卡 / 图标块 / 本人块 `linear-gradient(135deg, rgba(212,18,31,.11~.24), transparent 26% 或 rgba(255,255,255,.03~.05))`。
- 斜切：进度底板 `clip-path: polygon(0 0, 100% 0, calc(100% - 14px) 100%, 0 100%)` + 前缘 `skewX(-8deg)` 4px 亮红发光线；退场文字 `skewX(-6deg)`。

## 6. 布局骨架

- 外壳 `.app-shell`：flex，整体 14px 内边距与 14px 间距，侧栏 224px 固定宽，`.main` 自适应并 `padding: 16px 24px 64px`。
- 侧栏是一块 28px 圆角玻璃面板（18px/14px 内边距），内容：Logo（34px 红渐变方块 + 名称 + 大写副标）→ 导航项（40px 高、14px 圆角、13px/700、默认 `--muted`；悬停 4% 白底 + 9% 描边；激活 = 白字 + 16% 描边 + `linear-gradient(135deg, rgba(212,18,31,.28), rgba(255,255,255,.06))` + 内侧 1px 高光）→ 弹性空隙 → 用户芯片（头像 + 昵称 + 角色，14px 圆角 4% 底）。
- 页头：26px 标题 + 12.5px 副标 + spacer + 操作按钮，下边距 22px。
- 首页为网格卡片仪表盘：12 列 × 88px 行高、14px 间距；卡片 = 玻璃面板（22px 圆角）+ 眉标头 + 可滚动体；拖拽时红虚线幽灵框（`1.5px dashed var(--red-border)` + 7% 红底）与底板 9% 白虚线网格。
- 列表型页面：筛选栏（`filter-bar`，10px 间距）→ 行卡 / 网格卡 / 表格；网格卡 `repeat(auto-fill, minmax(210~230px, 1fr))`。
- 看板：列 = 玻璃面板 22px 圆角，`flex:1 1 0; min-width 224; max-width 380`，列头眉标 + 计数胶囊，卡片 14px 圆角 8px 间距，底部虚线「+ 添加」。

## 8. 动效规范

- 默认过渡 `0.15s`（背景 / 边框 / 颜色 / 阴影），卡片位移类 `180ms ease`，仪表盘卡片位置 `0.16s`，进度宽度 `0.45s cubic-bezier(.3,.9,.3,1)`。
- 浮层进场 `dd-in`：`from { opacity:0; transform: translateY(-4px) }` 0.12s。
- 定位闪烁 `focus-flash`：`0 0 0 2px rgba(255,55,72,.85), 0 0 22px rgba(255,55,72,.45)` 1.3s × 2 次；减少动态时改为静态红描边。
- **四象限优先级动效（看板卡片定稿 C2×B3）**：左缘 3px 色条（上下各留 12px）。红 = 急且重：色条 `quad-bar`（透明度 .4↔1 + 辉光）+ 整卡 `quad-breath` 呼吸红晕；金 = 仅重要：静态；橙 = 仅紧急：`quad-pulse` 透明度脉动；灰 = 普通：整卡 `opacity .68`。右上角 2×2 象限角标（8px 格 3px 间距 2.5px 圆角，上 = 重要 / 右 = 紧急，点亮格同色辉光）。周期与强度由根元素 `--fx-speed`（默认 1.8s）/ `--fx-glow`（默认 1）控制，提供「设置 → 显示设置」滑杆。
- **进度底板**：卡片底板即进度条，宽 `calc(var(--p) + 12px)`，斜切右缘，`repeating-linear-gradient(-55deg, 红 3.2% 0 10px, 红 1% 10px 20px)` 淡斜纹 4.2s 线性流动（位移 23px），前缘 4px 斜切亮红发光线，右下 46px 斜体描边进度数字。
- 今天线：2px 亮红竖线渐隐到底 + 红辉光，3s 呼吸。
- 开场动画（可选，品牌感强时用）：`#070707` 全屏 + 左上红晕，约 3.5s：终端引导自检文字（12px Consolas `#8f867d`，红色光标闪烁）→ 扫描线扫过 → Logo 故障砸入（`scale(1.9) blur(14px)` 0.3s 弹性，RGB 色散双层 `mix-blend-mode: screen`，碎片块闪烁，整体抖动）→ 标题乱码解密（`letter-spacing .5em`）→ 分层退场 + Logo CRT 压缩关屏（`scale(1.04,.012)` → `scale(.02,.008)`）。必须可点击 / Esc 跳过、可在设置中关闭、跟随 reduced-motion 自动跳过。
- **所有无限动画在 `@media (prefers-reduced-motion: reduce)` 下 `animation: none`**，并给出静态替代（如静态描边）。

## 9. 状态与语义色使用

| 语义 | 颜色 | 典型位置 |
| --- | --- | --- |
| 逾期 / 离线 / 错误 / 危险 / 急且重 | `--red-bright` 文字或红渐变色条、红辉光点 | 截止日期、状态点、系统提醒 🔴 |
| 临期（≤3 天）/ 警告 / 仅重要 / 低库存 / 重连中 | `--warn` 或 `#e8b54a` 金 | 截止日期、徽章、提醒 🟡 |
| 仅紧急 | 橙 `#ff8c3b` | 色条 / 角标 |
| 在线 / 成功 / 完成态 / 已识别 | `--ok` 绿 | 状态点、完成列标记、置信度高 |
| 普通 / 未知 / 未识别 | `--faint` 灰、虚线框、整卡降暗 | 角标、置信度低 |

排序约定：逾期红在前、临期金其次；来源徽章用 emoji（📋 任务 / 📽 项目 / 🔐 仓库 / 👥 人事 / ⚡ 系统 / 📢 公告 / 📌 提醒）。

## 10. 层级（z-index）约定

`body 背景 0` → `app-shell 1` → `仪表盘拖拽卡 50` → `移动端顶栏 60` → `甘特表头 20~31` → `弹窗 / 抽屉遮罩 100` → `抽屉 101` → `toast 200` → `图片灯箱 260` → `下拉菜单 300` → `右键菜单 400` → `拖影 500` → `确认 / 输入对话框 600` → `开场动画 1000`。新增浮层按此表插入，别随手写 9999。

## 11. 响应式（≤768px）

- 外壳改纵向 8px 内边距；侧栏变**置顶横向图标导航**（sticky top 8px，18px 圆角，`rgba(14,14,14,.92)` 实底，横向可滚且隐藏滚动条），导航只显示图标、当前页显示文字，Logo 只留方块，用户芯片只留头像。
- 标题 21px；表单 / 设置 / 入口网格单列；弹窗 `width: auto; max-width: 94vw`，遮罩从顶部 7vh 开始。
- **输入控件 16px 字号**（防 iOS 聚焦缩放）。
- 看板列最小宽 246px 整行横滑；甘特只留项目名列 150px；资产网格两列；触屏无 hover 的操作按钮常显。
- 中断点还有 1100px（首页双栏变单栏）、1000px（设置双栏变单栏）、1400px（速览卡片缩小）。

## 12. 工程约定

- 控件全自绘：Select / Modal / ContextMenu / confirmDialog / promptDialog / toast / Avatar 统一放 `components/ui.tsx`；禁止原生 `select / confirm / alert / prompt` 与浏览器默认右键菜单。
- 复制文本要兼容非 HTTPS 内网：clipboard API 失败时降级 `execCommand('copy')`。
- 前端相对路径（Vite `base: './'`）以支持子路径反代部署。
- 动效参数化：根元素 CSS 变量 `--fx-speed / --fx-glow`，用户可在设置调节并本地持久化。
- 拖拽用 pointer 事件自绘（`touch-action: none`、拖影 `rotate(1.6deg)` 红描边 `opacity .95`），目标位置用红虚线占位块。
- 富文本只允许 `b i u s br span[color]` 白名单。
- 中文 UI 文案；emoji 作为轻量图标（导航 / 来源徽章 / 空态）可以接受，不引入图标库也能成立。

## 14. 反模式（见到就改）

- 蓝 / 紫主色、霓虹青粉、大面积发光描边 —— 那是别家的赛博朋克。
- 纯 `#fff` 正文、`#000` 实心卡片、`#333` 灰块 —— 层次应靠白色透明度。
- 直角或 4~6px 小圆角的主要容器、方形按钮。
- 原生 select / confirm、浏览器默认右键菜单。
- 无投影的纯色红按钮、红色描边的普通卡片。
- 忽略 reduced-motion 的循环动画；忽略移动端 16px 输入。
- 把 z-index 写成 9999。
